# Changelog

## 1.1.0 (2026-11-26)

- Dukungan VS Code: editor dipilih otomatis (`-Editor auto|antigravity|vscode`).
- Program `input()` dijalankan dengan jawaban otomatis (`shot.ps1 -Jawab`), beberapa skenario dalam satu capture.
- Foto jendela GUI Tkinter tanpa mengubah kode (`gui_shot.py`), bingkai dan sudut bulat Windows dibuang.
- Blok `gambar` di content.json, beberapa jendela kecil bisa disusun berdampingan.
- Border gambar 1 pt warna tema "Black, Text 1" dengan ruang efek di keempat sisi.
- Pengaman: berhenti kalau fokus pindah atau ketikan masuk ke editor; `cek_notif.py` untuk notifikasi Windows.
- Contoh lengkap PBO Modul 1–5.

## 1.0.0 (2026-11-25)

- Rilis pertama: kode per nomor, screenshot kode dan output di Antigravity IDE, laporan dari template lama dengan
  struktur A sampai E, daftar pustaka APA, dan aturan format laporan.
